# Менеджер Баз Данных MySQL / PostgreSQL

Этот проект представляет собой инструмент для управления базами данных MySQL и PostgreSQL. Он предоставляет интерфейс для выполнения различных операций с базами данных, таких как создание, удаление, резервное копирование и восстановление баз данных, а также управление таблицами и данными.

## Стек технологий

- **PHP** - серверная логика и работа с базами данных
- **JavaScript** - клиентская часть и интерактивные элементы
- **Webpack** - сборка фронтенд-ресурсов
- **Composer** - менеджер зависимостей для PHP
- **NPM/Yarn** - менеджер пакетов для JavaScript

## Установка и настройка

### Зависимости

Для установки необходимых инструментов разработки выполните следующие команды:

#### PHP инструменты
```bash
# PHP_CodeSniffer для проверки соответствия стандартам кодирования
composer global require "squizlabs/php_codesniffer=*"

# PHP-CS-Fixer для автоматического форматирования кода
composer global require --dev friendsofphp/php-cs-fixer

# PHPStan для статического анализа кода
composer global require --dev phpstan/phpstan
```

#### Форматирование кода
Для форматирования JavaScript/TypeScript файлов используйте Prettier:
```bash
# Запуск форматирования для всех файлов
npx prettier . --write
```

### Сборка проекта

Для сборки фронтенд-части проекта используйте Webpack:
```bash
npx webpack
```

Или выполните скрипт сборки:
```bash
# В Windows
.\utils.ps1
```

## Структура проекта

- `init.php` - основной файл инициализации приложения
- `composer.json` - зависимости PHP проекта
- `package.json` - зависимости JavaScript проекта
- `webpack.config.js` - конфигурация сборки Webpack
- `.babelrc` - конфигурация транспиляции JavaScript
- `.prettierrc` - настройки форматирования кода
- `.php-cs-fixer.dist.php` - настройки форматирования PHP кода
- `phpstan.neon` - конфигурация статического анализа PHP кода

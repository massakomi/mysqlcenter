# Менеджер Баз данных MySQL / PostgresSQL

Билд фронтенда  npx webpack

Билд фронтенда и необходимые команды можно запустить через utils.ps1


### Установка зависимостей

codesniffer
composer global require "squizlabs/php_codesniffer=*"

cs-fixer
composer global require --dev friendsofphp/php-cs-fixer

phpstan
composer global require --dev phpstan/phpstan


### Prettier
https://prettier.io/docs/options#semicolons

Запустить на всех файлах форматирование

npx prettier . --write
